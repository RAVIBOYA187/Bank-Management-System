# 🏦 Bank Management System (Core Java)

## 📌 Project Description
A console-based Bank Management System developed using Core Java, implementing core OOP principles such as Inheritance, Polymorphism, Abstraction, and Encapsulation.

---

## 🚀 Features
- Account Creation (Savings & Current)
- Deposit & Withdraw
- Transaction History
- Balance Validation
- Different Account Types with Polymorphism

---

## 🧠 OOP Concepts Used
- Abstract Classes
- Interfaces
- Inheritance
- Polymorphism
- Encapsulation
- Composition & Aggregation
